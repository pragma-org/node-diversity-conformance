Yano is a Cardano data node in Java, built on [Yaci](https://github.com/bloxbean/yaci) (the Ouroboros mini-protocols) and [Cardano Client Lib](https://github.com/bloxbean/cardano-client-lib). It syncs and relays the chain, computes its own ledger state, validates transactions with its own ledger rules and the [JuLC](https://github.com/bloxbean/julc) Plutus evaluator, and runs as a standalone node or as an embeddable library.
