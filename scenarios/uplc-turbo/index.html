UPLC turbo benchmarks

Method

Each implementation decodes and evaluates the same flat-encoded UPLC corpus. The corpus has been created by sampling mainnet transactions, extracting scripts and pre-applying their script context. The corpus is therefore filled with thousands of ready-to-evaluate 'real world' UPLC scripts spanning across Plutus V1, V2 and V3. Every measure is done 10 times, looking at mean/max wall-clock measurements and memory usage across the samples. Measurements include both flat decoding and CEK evaluation.

The benchmark compares evaluation time and memory growth with the expected CPU and memory budgets. An execution passes when each available deviation is at most 50% from the estimated cost. The report retains every script, while the compact view shows the ten slowest cases selected by the active node and ordering.
