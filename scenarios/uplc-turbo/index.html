UPLC turbo benchmarks

Method

Each implementation decodes and evaluates the same flat-encoded UPLC corpus. The corpus has been created by sampling mainnet transactions, extracting scripts and pre-applying their script context. It therefore contains ready-to-evaluate real-world scripts spanning Plutus V1 and V2. Each report provides one representative measurement for flat decoding, pure CEK evaluation, and memory usage.

The benchmark compares evaluation time and memory growth with the expected CPU and memory budgets. CPU evaluation and flat decoding are measured separately, but their combined time is checked against the CPU budget. An execution passes when the combined CPU-related time is at most 50% above that budget; differences below 100 μs are treated as within tolerance. The report retains every script, while the compact view shows the ten slowest cases selected by the active node and ordering.
