CARDANO / CONFORMANCE

Node diversity

This site analyzes conformance across Cardano node implementations. It is a best-effort at measuring compatibility and uniformity across implementations, through a variety of functional and non-functional conformance scenarios.

Conformant nodes agree with each other. They accept the same valid inputs, reject the same invalid ones, and behave comparably when performance matters. The conformance scenarios are node-agnostic: any node implementation can run them.
