Scarab is a Cardano-compatible node in Scala 3, written as functional, tagless-final code with cats-effect and cats-mtl, and checked against the Haskell cardano-node as its reference. It is unofficial research software and has not been audited.

Its reports are written by the `tools` module of its repository, through the node's production decoders, ledger rules and Plutus evaluator. The Plutus results (the UPLC functional tests, the UPLC benchmarks and the scripts of the ledger rules scenario) are those of Scarab's own evaluator, not of Scalus, which the node uses by default. They are published on demand to [KD5UJC-XYZ/scarab-conformance](https://github.com/KD5UJC-XYZ/scarab-conformance), each beside a provenance file that names the Scarab commit and the inputs it was run on.
